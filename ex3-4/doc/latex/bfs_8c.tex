\doxysubsection{Detailed Description}
Implementation of Breadth-\/\+First Search algorithm for graphs. 

This file contains the implementation of a breadth-\/first search algorithm that can be used with any graph implementation that provides the required interface.

Implements the breadth-\/first search algorithm using a queue. The function measures and prints the execution time. The returned array must be freed by the caller.

\begin{DoxyNote}{Note}
The hash parameter is used for compatibility with the graph interface but is not essential for the BFS algorithm itself. 
\end{DoxyNote}
